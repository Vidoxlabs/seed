# Seed architecture decision records

Architecture decision records in `seed` follow the [hub ADR convention](https://github.com/Vidoxlabs/docs/blob/main/docs/adr/README.md) and [ADR template](https://github.com/Vidoxlabs/docs/blob/main/docs/adr/template.md) on `Vidoxlabs/docs`.

ADRs here are numbered sequentially from `0001` as `docs/adr/NNNN-<slug>.md`. Agents write proposals with status `Proposed`; only an owner decision moves a record to `Accepted`, and any runtime dependency proposal requires an ADR first. No ADRs exist in `seed` yet.
