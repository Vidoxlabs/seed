# Seed capabilities

This folder holds the `seed` capability ledger (`index.json`) and lead capability specifications (`CAP-NN-<slug>.md`).
Cross-repository milestones, dependencies, and the family ledger live in the [hub timeline](https://github.com/Vidoxlabs/docs/blob/main/docs/timeline/README.md) on `Vidoxlabs/docs`.
Any pull request that starts, advances, or lands a capability slice updates `index.json`, the owning spec's `Evidence` and `Changes` sections, `docs/CHANGELOG.md`, and any touched contract `Changes` section in the same PR.
